# SK Home Care Website

A responsive static website for SK Home Care built with React, Vite, React Router and Tailwind CSS v4. All page/component styling is done with Tailwind utility classes; there is no custom external stylesheet. `src/index.css` only imports Tailwind.

## Requirements
- Node.js 20.19+ or 22.12+

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Pages
- Home
- About Us
- Our Services
- Contact

The site is static and has no admin panel, database, or backend. Images are demo images and can be replaced later. Phone links, email links, WhatsApp and the Google Maps embed are included.
